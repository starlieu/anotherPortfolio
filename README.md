# anotherPortfolio
A minimalist, modern, and dark personal portfolio built with HTML, CSS, and Vanilla JS.

## Repository
- **Portfolio Source Code**: [https://github.com/starlieu/anotherPortfolio](https://github.com/starlieu/anotherPortfolio)

## Features
- **Title**: Customisable title (`anotherPortfolio`).
- **Bio & Identity**: Includes badges, custom links, and social connections.
- **Visual Style**: Dark violet palette (`#350c6b`), subtle glow effects, discrete particle background.
- **Performance**: Lightweight Vanilla JS, no external libraries or heavy dependencies.
- **Responsive**: Mobile-first design with smooth dynamic scaling.
- **Accessibility**: Full `prefers-reduced-motion` support.

## 🚀 How to Launch on GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com) and click **New repository**.
   - Choose a name for your repository (e.g., `anotherPortfolio` or `your_username.github.io`).
   - Set visibility to **Public** and click **Create repository**.

2. **Add Project Files**:
   - Upload or create the project files at the root of the repository:
     - `index.html`
     - `style.css`
     - `script.js`
     - `README.md`
     - `LICENSE`

3. **Enable Hosting**:
   - Open your repository settings (**Settings** > **Pages**).
   - Under **Build and deployment**, set **Source** to `Deploy from a branch`.
   - Select the `main` branch and `/ (root)` folder, then click **Save**.
   - Your site will be online in a few moments at `https://your_username.github.io/`.

## ✏️ How to Edit the Site

### Option 1: Directly on GitHub (Web Browser / Mobile)
1. Navigate to your repository on GitHub.
2. Click the file you want to edit (e.g., `index.html` for content, `style.css` for design).
3. Click the pencil icon (**Edit this file**) in the top right.
4. Make your changes, then click **Commit changes...** at the top right to save.
5. The live site will automatically update within 1 to 2 minutes.
